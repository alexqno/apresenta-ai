# Design de apresentação

Adapte este diretório antes de usá-lo. Ele define estrutura mínima, não uma
identidade visual pronta.

1. Registre objetivo, público e referências em `design-rationale.md`.
2. Defina tokens semânticos em `tokens.css`.
3. Ajuste ou remova componentes em `components.css` conforme os padrões
   necessários.
4. Guarde ativos aprovados em `assets/` e documente origem, licença e uso.
5. Valide contraste, projeção em 16:9 e modo de movimento reduzido.
